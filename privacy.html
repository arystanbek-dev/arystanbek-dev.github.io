Privacy Policy

Order Scout for Threads · Last updated: 2026-10-21

Order Scout is a small tool built and operated by an independent video editor and bot developer (Arystan Motion, Astana, Kazakhstan). It helps the operator find people who are publicly looking to hire a video editor or a Telegram bot developer on Threads. This policy explains what data the app uses and how.

What the app does

  • Searches recent public Threads posts for keywords the logged-in user enters (Threads API threads_keyword_search).
  • Identifies the logged-in Threads user (username and user ID) through threads_basic.
  • It never posts, replies, likes, follows or sends messages on anyone’s behalf. Any contact with a post’s author is made manually by the user in the Threads app.

Data we collect

  • Logged-in user: Threads user ID, username and the access token issued by Meta.
  • Search results: text, author username, link and time of public posts that match the keywords.

We do not collect passwords, email addresses, phone numbers, private messages, contacts or location data.

How we use it

Data is used only to show search results to the logged-in user and to avoid showing the same post twice. It is not sold, shared with third parties, used for advertising or used to build profiles of people.

Storage and retention

  • Data is stored on a private server operated by us.
  • Post text and author usernames are kept for 30 days, then deleted automatically.
  • The access token is kept until it expires, the user logs out, removes the app in Threads settings or requests deletion.

Your choices and deletion

You can remove the app at any time in Threads: Settings → Account → Website permissions. When the app is removed, we delete your token and any data linked to your account. You can also request deletion manually — see Data Deletion.
