# Arystan Motion — портфолио сайты

https://arystanbek-dev.github.io — монтаж, логотип анимациясы, моушн видео, бот пен сайт жобалары.

- `index.html`, `style.css`, `app.js` — бет; мәтін үш тілде (kk/ru/en) `app.js`-те.
- `media/` — видео (720p) мен мұқабалар. Freelance Ops репосындағы `motion/tools/site_media.sh` жасайды.
- `taplink/` — Taplink кейсі (жаңа жылдық безендіру, «до / после»): https://arystanbek-dev.github.io/taplink/.
  Freelance Ops репосындағы `design/taplink/build.py` жасайды, қолмен өзгертілмейді.
- `privacy.html`, `data-deletion.html` — Order Scout (Threads API) қосымшасының беттері.
